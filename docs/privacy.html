Privacy Policy

Effective date: July 23, 2026

In short: Meguri does not collect any personal data. Your media and catalogue stay on your machine. The network features are optional update checks and Pexels source previews, described below.

Data stored locally

Meguri indexes the folders you point it at and stores the resulting data only on your device:

  • The media index (file paths, metadata, tags, favorites, ratings, bookmarks, play history) is kept in a local SQLite database.
  • Thumbnails and preview images are generated and cached locally.
  • Application settings are saved in a local configuration file.

The developer has no access to your local catalogue. Meguri reads your media files to index and play them.

Network access

For optional update checks, Meguri queries the GitHub API (api.github.com) for the latest release of Meguri to let you know when a new version is available.

  • The request contains no personal data or identifiers beyond what any HTTP request technically exposes (such as your IP address), which is processed by GitHub under the GitHub Privacy Statement.
  • The automatic check on startup can be turned off in the app's settings; updates can then only be checked manually.

When you open the source review, Meguri requests preview images from images.pexels.com for the Pexels upload IDs it displays. These requests contain the public Pexels IDs and standard HTTP request metadata. Local video, thumbnails, filenames, and paths stay on your device.

Meguri serves local media to the app through a server bound to 127.0.0.1, which is not reachable from other devices.

Analytics and telemetry

Meguri contains no analytics, telemetry, crash reporting, advertising, or tracking of any kind. There are no user accounts and no cloud services.

Third parties

GitHub receives standard request metadata for optional update checks. Pexels receives public upload IDs and standard request metadata for source previews. See “Network access” above.

Changes to this policy

If Meguri's behavior ever changes in a way that affects this policy, this page will be updated and the effective date above will be revised.

Contact

Questions about this policy can be raised on the GitHub issue tracker.
